# 拾光便签原生适配记录

2026-10-14，独立项目；目标 fnOS 1.2.0800、Intel/AMD，飞牛 App 1.37.0。用户自行安装验收，不要求 NAS SSH。

- 完整入口为根目录 React/Express；`fnos/m0` 仅为早期预检和复用辅助模块。原生开关为 `FNOS_NATIVE=1` 与 `VITE_FNOS_NATIVE=1`，构建/打包使用 `npm run fnos:build` / `fnos:pack`。
- 保留包标识 `fnnotes-m0` 与 `/app/fnnotes-m0/`；应用版本 0.2.1、上游固定 1.12.0 / `6a9b6a3f02a3dd189117bd511d840e44e0c665d5`。NAS 会话来自网关，账号管理在 NAS 完成；不收集 NAS 密码。
- 私有与授权共享空间由服务端检查权限。PNG 在客户端生成；生产 FPK 无浏览器运行时、Docker、模拟入口或测试数据。独立 PC/macOS/Android 包仍为后续目标。
- 左下账号入口为用户名首字头像，并非 NAS 真实照片。相邻原按钮控制分类栏；编辑/预览在顶部菜单。主题选择器在实时预览右下角。
- 测试 CSS 视口高于外窗可见内容区会裁切底部控件；0.2.1 用 1366×650 验证底部入口，并检查 390/1024 px 设置。界面对照见 `design-qa.md`。
- 此次上游 196 项、原生/辅助 15 项及真实浏览器核心/图片/共享/界面检查通过。NAS 身份网关、文件 ACL、手机 App 保存与包生命周期尚未真机验收，外部服务需用户自己的配置单独测试。
