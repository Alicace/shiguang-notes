# 拾光便签应用图标来源

## 应用中心与桌面图标

`public/brand/shiguang-app-icon.png`（1024×1024 px，透明圆角）由项目维护者提供。
画面是便签纸、绿色铅笔和金属回形针组成的拟物图标。应用中心与桌面的
64/256 px 图标、浏览器 favicon、登录页、页眉和关于页都从这一张源图生成。

`fnos/tools/make_brand_assets.mjs` 只维护内置页脚标志，不生成或覆盖应用图标；
避免后续重新运行工具时把用户提供的图标改回旧设计。

## 内置页脚标志

`public/brand/shiguang-footer-logo.png`（48×48 px，带透明通道）为浅米色圆底与
近白色「S」字形。公众号会把页脚图按圆形裁剪，因此导出为四周透明的圆形徽标。

主题选择器中的色卡使用各自的主题插画，与上述两个品牌资源用途不同。
