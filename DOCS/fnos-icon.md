# 拾光便签应用图标来源

## 应用中心与桌面图标

`public/brand/shiguang-app-icon.png`（1024×1024 px），本项目自绘：暖米色高光圆角底、
带纸张厚度与柔和投影的便签纸，以及一支带金属环、笔夹、笔握纹理与圆柱高光的深棕笔。
只使用「便签 + 笔」这一通用概念，不使用上游应用的手写文案、红色 HB 铅笔、木纹背景
或任何上游美术资源，因此与上游图标不构成同一标识。

登录页、页眉、应用中心与桌面都直接引用这张自绘图标；旧的 `public/header/logo.png`
不再进入登录页或页眉。

## 内置页脚标志

`public/brand/shiguang-footer-logo.png`（48×48 px，带透明通道），同样是自绘图形：浅米色圆底 + 近白色「S」字形，配色取自上一版内置页脚标志的浅米色（`#e9e3da`），避免深色块在暖白纸面上形成过重的视觉。公众号会把页脚图按圆形裁剪，因此导出为四周透明的圆形徽标。

主题选择器里的「暖白纸感 / 深夜便签」色卡继续使用 `public/smartisan-theme-icon.png`（纸张与铅笔插画），与应用图标用途不同：前者是主题外观的示意缩略图，后者是应用在应用中心与桌面的标识。

两个品牌图形都由 `fnos/tools/make_brand_assets.mjs` 生成（纯 SVG + sharp，不依赖上游美术），重新运行会同时写出这两份文件。
